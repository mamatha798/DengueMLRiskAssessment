Project Information

About Dengue AI Guardian

An educational prototype developed to support dengue awareness through technology.

🎯 Project Purpose

Dengue AI Guardian is an educational dengue awareness and monitoring prototype designed to support early awareness through symptom recording, weather monitoring and government-reported dengue statistics.

It provides a simple way to explore dengue information and maintain symptom records.

💻 Technology Stack

Programming: Python

Database: SQLite

Data Processing: Pandas

Weather API: Open-Meteo

Government Data: NCVBDC

Web Technologies: HTML, CSS and JavaScript

Developed By: Mamatha

⚠️ Medical Safety Disclaimer: This prototype does not diagnose dengue, calculate a clinically validated dengue risk score or replace professional medical advice. The symptom count is not a diagnosis. If severe abdominal pain, persistent vomiting, bleeding, difficulty breathing, confusion or cold/clammy skin occurs, seek urgent medical care.
